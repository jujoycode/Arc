# arcat 브랜드와 삼색 집배원 고양이

> 갱신일: 2026-10-13 KST · 전체 KRDS 적용 후 중립 라이트 테마·삼색 포인트·상황별 인터랙션

제품 표기는 소문자 **arcat**을 사용한다. KRDS의 토큰 계층·접근성·정보 구조를 바탕으로 흰색·중립 회색의 깔끔한 라이트 테마를 제공한다. 삼색 집배원 고양이는 로고·캐릭터와 작은 행동·선택·데이터 포인트에 사용한다. 캐릭터는 팀이 업무를 전달하고 함께 마무리하는 경험을 표현한다.

## 캐릭터와 자산

고양이 털은 **크림색 바탕·진저색 무늬·차콜색 무늬**의 삼색이다. 모자나 가방만 세 가지 색으로 칠해 삼색 고양이를 대신하지 않는다. 구리색 집배원 모자, 차콜 우편 가방과 편지는 역할을 보여 주는 식별 요소다. 마크·기본 인사·시선 추적·눈 가림·편지 전달·축하 자세는 같은 얼굴과 털 무늬를 유지한다.

생성한 원본은 [브랜드 자산](brand/README.md)에 모은다. 앱은 CSS로 크기·배치·짧은 동작을 조절한다. 캐릭터는 업무 내용을 가리지 않는 보조 요소이며 중요한 메시지는 항상 텍스트로 제공한다.

## 제품 색상

| 역할 | 값 | 적용 |
| --- | --- | --- |
| 흰색 표면·종이 | `#FFFFFF` | 헤더·탐색·카드·폼·대화상자·인증 패널 |
| 중립 바탕 | `#F7F8FA` | 전체 앱 배경 |
| 중립 보조 표면 | `#F2F4F7` | 보조 영역·데이터 헤더 |
| 기본 글자 / 보조 글자 | `#20242B` / `#59616D` | 제목·본문 / 메타 정보 |
| 구분선 / 입력 경계 | `#E2E5E9` / `#7A818B` | 장식적 경계 / 식별 가능한 컨트롤 |
| 구리색 포인트 | `#A64B2A` / hover `#873B21` | 주 행동·링크·포커스·작은 선택 표시·데이터 강조 |
| 옅은 선택 바탕 | `#FFF6EF`, 글자 `#20242B` | 작은 선택 조작 |
| 진저색 | `#DF995B` | 캐릭터·로고의 포인트 |

큰 화면 면적은 흰색·중립 회색으로 구성한다. 로그인·온보딩·사이드바·빈 상태에도 베이지/크림 전체 배경, 갈색 본문·테두리, 큰 장식 원과 그라데이션을 사용하지 않는다. 삼색 털·이미지·마우스 시선·눈 가림·전달·축하 동작은 유지한다.

활성 탐색과 간트의 선택 행은 중립 회색 바탕에 작은 구리색 표시를 둔다. 데이터 배지·배정 안내·선택 상세 패널은 흰색·중립 회색을 사용한다. 간트 남은 구간은 `#E2E5E9`, 완료 구간은 업무 `#A64B2A`·Epic `#4C5665`·Bug 오류 색으로 구분한다. 옅은 선택 바탕을 넓은 안내 패널에 확장하지 않는다.

진저색은 흰색과의 대비가 낮아 작은 글자·입력 경계·주 버튼에 사용하지 않는다. 오류·성공·주의는 별도의 의미 색과 문구로 유지한다. 화면은 원시 색상 대신 `--arc-color-*`를 소비하며, 정확한 토큰과 대비 근거는 [디자인 가이드](DESIGN_GUIDE.md#색상-토큰)에 기록한다.

[실제 제품 사진 50장](product/README.md)은 전체 KRDS 정비를 검증한 앱 소스 `a337c2809c10e453f96841909d77d8431ec93ef1`을 촬영 중 고정해 2026-10-13 KST에 갱신했다. 원본은 모두 1920×1080·DPR 1이며 이후 문서 커밋과 앱 소스 기준은 구분한다. 삼색 이미지·시선·눈 가림·모션 감소·터치 동작의 회귀와 자동 검사의 범위는 [디자인 검증](DESIGN_VERIFICATION.md)을 따른다.

## 화면 적용

- 상단 탐색: 삼색 얼굴 마크와 `arcat` 글자를 함께 사용한다. 프로젝트 사이드바에는 같은 로고를 반복하지 않는다. 작은 화면에서도 프로젝트 이름과 탐색 조작 공간을 확보한다.
- 로그인·가입: 넓은 안내 패널의 캐릭터가 마우스 방향을 눈으로 보고 몸을 조금 기울인다. 작은 화면에서는 입력 공간을 우선한다. 비밀번호에 초점을 두면 앞발로 눈을 가리는 자세로 전환한다.
- 온보딩: 가입·이메일 확인·첫 워크스페이스/프로젝트 안내에는 인사·편지 전달 등 상황에 맞는 자세를 사용한다.
- 티켓과 설정: 배정 안내·저장 결과·비어 있는 업무 안내에 작은 캐릭터와 짧은 동작을 적용한다. 기본 자세 하나를 모든 상황에 반복하지 않고 전달·축하 자세로 의미를 구분한다. 현재 제공하지 않는 알림 수신 기능이 있는 것처럼 표현하지 않는다.
- 업무 빈 상태: WBS에 실제 티켓이 없을 때는 인사 자세와 역할에 맞는 다음 행동을, 조회를 마쳤지만 진행 중 스프린트가 없을 때는 차분한 자세와 안내를 제공한다. 필터 결과만 비어 있거나 조회 중·실패 상태이면 빈 업무 캐릭터를 대신 표시하지 않는다.
- GitHub: 제품명·로고·배너·기능 설명과 실제 제품 화면 자료를 갱신한다.

## 동작과 접근성

### 시선과 개인정보

- 시선 추적은 해당 화면이 `interactive`를 지정하고, 정밀 포인터와 모션 허용 환경이 모두 충족될 때 활성화한다. 터치 동작은 추적하지 않는다.
- 시선 추적 화면에서는 인사·전달 같은 등장 모션을 함께 재생하지 않는다. 모션 감소·터치 중심 환경은 기본 정지 자세로 돌아간다.
- 최신 포인터 위치만 한 프레임씩 반영한다. 몸 이동은 최대 가로 5px·세로 3px·회전 1.4도이며 눈동자도 제한된 범위에서 움직인다. 페이지 밖으로 포인터가 나가거나 창이 초점을 잃으면 중심으로 돌아온다.
- 비밀번호 **초점 상태**만으로 `privacy`를 전환한다. 비밀번호 값이나 입력 길이를 읽어 모션에 전달하지 않는다. 눈을 가리는 동안 시선 추적을 멈추고 위치를 초기화하며, 초점을 옮기면 정상 자세를 복원한다.
- 모션 감소·굵은 포인터 환경에서는 정지 자세를 제공한다. 비밀번호 초점의 정지 눈 가림 이미지는 유지한다. 환경이 바뀌거나 컴포넌트를 닫으면 이벤트·애니메이션 프레임을 정리한다.

### 짧은 상황별 동작

인사·편지 전달·저장 축하·마크 반응은 유한한 동작이다. 폼 입력과 표를 방해하는 지속적인 큰 움직임은 피한다. `prefers-reduced-motion`에서는 시선 추적과 장식 애니메이션을 모두 멈추며, 업무 결과·오류·다음 행동은 그대로 제공한다. 장식 이미지는 빈 대체 텍스트를 사용하고 제품 로고 링크에는 arcat을 포함한 접근 가능한 이름을 제공한다.

공통 `Mascot`의 `variant`는 `welcome`, `deliver`, `celebrate`, `idle`이며 `size`, `label`, `className`으로 배치를 조절한다. `interactive`와 `privacy`의 기본값은 `false`다. 로그인 이외의 화면에서는 필요한 순간의 자세를 명시하며 시선 추적을 자동으로 켜지 않는다.

제품명 변경은 데이터 식별자·API 경로·이미 배포된 환경 변수와 독립적으로 적용한다. 화면과 새 이메일의 제품명을 통일하고 기존 인증·필드 설정·권한 동작을 검증한다.
