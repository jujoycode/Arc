# arcat 브랜드와 집배원 고양이

> 갱신일: 2026-10-10 · 사용자 요청에 따른 제품명·캐릭터 확장

제품 표기는 소문자 **arcat**을 사용한다. KRDS 기반의 기존 색상·접근성·정보 구조를 유지하면서 따뜻한 집배원 고양이로 팀의 업무 전달 경험을 표현한다.

## 캐릭터와 자산

크림색 고양이, 짙은 파란색 집배원 가방, 작은 편지와 산호색 포인트를 사용한다. 생성한 동일 캐릭터를 로그인·가입·첫 워크스페이스 안내, 로고·favicon·README 배너에 연결한다. 캐릭터는 업무 내용을 가리지 않는 보조 요소이며 중요한 메시지는 항상 텍스트로 제공한다.

## 화면 적용

- 로그인·가입: 넓은 화면의 안내 패널에 큰 캐릭터와 제품 소개를 배치한다. 작은 화면에서는 입력 공간을 우선한다.
- 온보딩: 가입·이메일 확인·첫 워크스페이스/프로젝트 안내에 편지를 전달하는 캐릭터를 사용한다.
- 티켓과 설정: 배정 안내·성공 메시지 등 의미가 있는 순간에 작은 캐릭터와 짧은 전달 동작을 적용한다. 현재 제공하지 않는 알림 수신 기능이 있는 것처럼 표현하지 않는다.
- GitHub: 제품명·로고·배너·기능 설명과 실제 제품 화면 자료를 갱신한다.

## 동작과 접근성

애니메이션은 짧은 등장·손인사·편지 전달을 CSS로 구현한다. 폼 입력과 표를 방해하는 지속적인 큰 움직임은 피한다. `prefers-reduced-motion`에서는 정지 이미지로 제공하며 장식 이미지는 빈 대체 텍스트를 사용한다. 제품 식별용 로고에는 arcat 대체 텍스트를 제공한다.

제품명 변경은 데이터 식별자·API 경로·이미 배포된 환경 변수와 독립적으로 적용한다. 화면과 새 이메일의 제품명을 통일하고 기존 인증·필드 설정·권한 흐름을 검증한다.
