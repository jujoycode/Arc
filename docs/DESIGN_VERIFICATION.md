# arcat 디자인 시스템 v2 검증

> 갱신일: 2026-10-11 · 기준: [디자인 가이드](DESIGN_GUIDE.md), [재기획](DESIGN_REPLAN.md)

## 적용 범위

- 기본 → 의미 → 컴포넌트 → 패턴 토큰을 정의하고 shadcn/ui·Tailwind v4에 연결했다.
- 앱 셸에 워크스페이스 위치, 실제 프로젝트 선택, 계정과 로그아웃을 적용했다. 모바일은 하단 보기 탐색을 사용한다.
- 간트 기간·출력, 필터, 표시 옵션, 개인 보기를 구분했다. 간트 좌측 계층·시간축은 48px 행을 공유하며, 완료·남은 구간과 관계선에 패턴 토큰을 적용했다.
- 칸반과 스프린트의 공통 이슈 카드에 상세 링크, 유형, 우선순위, 담당자, 포인트, 완료 예정일과 키보드 상태 선택을 제공한다.
- 백로그·목록의 글자·입력·정렬 조작을 통일하고 적용 필터를 개별 해제할 수 있게 했다.
- 설정과 생성 폼에 지속적으로 보이는 레이블을 적용하고 팀원 관리 버튼이 좁은 화면에서 줄바꿈되도록 했다.

## 재현 가능한 검사

`pnpm --dir frontend check:browser`는 자체 워크스페이스·프로젝트·이슈·멤버를 만든 뒤 아래를 검사하고 워크스페이스를 정리한다. API·MySQL·메일 수신함이 필요하며 실행 주소는 [개발·검증 안내](DEVELOPMENT.md)를 따른다.

| 검사 | 대상 |
| --- | --- |
| axe WCAG 2 A/AA, 2.1 A/AA, 2.2 AA 자동 규칙 | 이슈 생성 대화상자, 간트·WBS·타임라인·칸반·백로그·스프린트·이슈 목록·설정, 하위 티켓 생성 대화상자 |
| 문서 가로 넘침 | 각 화면 360·768·1280 CSS px |
| 확대 시 재배치 | 1440 물리 px에 해당하는 720 CSS px / DPR 2 환경 |
| 키보드 대체 동작 | 간트 항목 선택, 네이티브 카드 상태 변경, 표시 옵션 펼치기 |
| 운영체제 표시 설정 | forced colors + reduced motion에서 간트 옵션 조작 |
| 실패 상태 | 상태 이동 409 후 이전 상태 유지와 재시도, 편집 충돌 시 입력 보존 |
| 출력 | 선택 기간·열의 PNG 크기와 PDF 형식 |

접근성 결과 JSON은 `ARC_TEST_OUTPUT` 아래에 저장한다. CI에서는 `acceptance-artifacts`에 포함한다. 실패 시 스크린샷과 Playwright 추적을 함께 남긴다.

자동 검사에서 위반 0건을 확인했다. 이 결과는 수동 화면 읽기 도구 검증이나 전체 WCAG 인증을 의미하지 않는다. 확대 검사는 브라우저 네이티브 줌 조작 대신 같은 CSS 화면 폭과 DPR로 재배치를 검증한다. 실기기 화면 읽기 도구, 다크 모드, 사용자별 밀도, 마지막 보기 기억은 후속 검토 항목이다.

WBS·타임라인을 포함한 8개 주요 화면의 axe 위반 0건과 360/768/1280px·확대 재배치가 통과했다. 새 하위 티켓 대화상자도 위반 0건이다. CI 수용 자료에 `wbs-1920.png`와 `timeline-1920.png`를 1920×1080으로 보관한다. 새 뷰의 대량 데이터 성능·실기기 화면 읽기 도구는 이번 기능 수용 검사 범위 밖이다.

## 2026-10-11 중립 라이트 테마와 삼색 포인트

코드 `0717ff1`에서 흰색 표면·밝은 회색 배경과 중립 글자·경계를 적용했습니다. 삼색은 캐릭터·로고·주 행동·작은 선택/초점·데이터 강조에 한정합니다. 로그인 장식 원·그라데이션과 큰 베이지 면을 제거하고 README 배너도 밝게 갱신했습니다. 기존 입력 높이·행 높이·권한·API·캐릭터 이미지와 동작은 유지합니다.

프런트 경계·TypeScript·빌드와 lint가 통과했으며 lint의 기존 경고는 유지됩니다. 실제 MySQL·Mailpit·프로덕션 웹 번들에서 전체 API, GitHub/GitLab 모형 연동, 기본 브라우저, 티켓 필드 API/브라우저와 삼색 브랜드 브라우저 검사가 모두 성공했습니다. 브랜드의 8개 상태×1920/768/360px 접근성 결과 24개는 위반 0건입니다. 중첩 간트/WBS·PNG/PDF·스프린트·역할별 실행·필드 오류/충돌·입력 보존·모션 감소·터치·비밀번호 보호를 같은 기존 흐름으로 확인했습니다.

1920×1080 로그인과 360px 로그인·직접 여는 HTML 시안을 캡처해 검토했습니다. 운영체제의 dark 설정에서도 `color-scheme: light`로 표시하고, 넓은 면은 중립색이며 로그인 장식 원은 표시하지 않습니다.
