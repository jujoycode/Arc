## 현재 진행

- [x] GitHub Actions CI를 구성하고 [main 실행](https://github.com/jujoycode/Arc/actions/runs/37341400334)에서 모든 검사의 성공을 확인했다. 프런트·백엔드 검사, 빌드 결과의 API·브라우저 수용 검증, 실패 자료 수집을 제공한다. [CI 문서](CI.md)
- [x] 프런트 패키지 관리를 pnpm 11.19.0으로 전환하고 잠금 파일로 설치를 재현한다.
- [x] 프런트를 app·8개 기능·shared로 구조화하고 공개 진입점·의존 경계 검사를 빌드에 적용했다. [구조 문서](FRONTEND_ARCHITECTURE.md)

- [x] 백엔드 구조 정리: 기능별 모듈, `api` 공개 계약, `internal` 서비스·저장소, `web` HTTP 진입점으로 분리했다. 기존 API와 권한·트랜잭션 동작을 검증했다. [구조 문서](BACKEND_ARCHITECTURE.md)
- [x] 기존 명세 보완: 보관 프로젝트 변경 제한, 첫 이슈 등록 전 프로젝트 키 변경, 스프린트 종료 포인트 요약과 활동 기록을 완성했다.

## 기존 요청의 후속 작업

- [ ] Exposed 전환을 남은 JDBC 저장소로 확대한다. 같은 유스케이스의 트랜잭션과 잠금 동작을 보존한다.
- [x] 서버 필터와 보기 간 필터 상태 공유를 정리했다. 목록·보드·간트·백로그·스프린트에서 공통 조건을 유지한다.
- [ ] 대량 간트·보드·백로그의 성능과 변경 실패 복원 흐름을 점검한다.
- [ ] Docker Compose 기반 배포 구성을 준비하고 Get Started를 재현 가능하게 유지한다. 사용자가 자체 서버 Compose 방향을 선택했다. 운영 도메인·SMTP 연결은 실제 배포 환경에서 설정한다.
- [ ] GitHub·GitLab 연동은 [연동 명세](INTEGRATIONS.md)의 경계에 맞춰 후속 릴리스로 구현한다.
