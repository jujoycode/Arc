# arcat 브랜드 자산

집배원 고양이는 팀의 업무를 전달하는 arcat의 캐릭터입니다. 크림색·진저색 몸, 산호색 집배원 모자, 네이비 우편 가방과 편지가 식별 요소입니다.

| 자산 | 용도 |
| --- | --- |
| [캐릭터 원본](../../frontend/public/brand/postcat.png) | 로그인·온보딩·티켓 배정·상태 안내의 투명 PNG |
| [브랜드 마크](../../frontend/public/brand/arcat-mark.png) | 앱 로고·favicon·터치 아이콘의 투명 PNG |
| [README 배너](arcat-banner.png) | GitHub 제품 소개 |

이미지 생성 도구로 제작한 원본을 그대로 사용합니다. 배너는 브랜드 일러스트이며 [실제 제품 화면 사진](../product/README.md)과 구분합니다. 앱에서는 CSS로 크기를 조절하고 짧은 전달·축하 동작을 적용합니다. 모션 감소 설정에서는 정지 이미지로 표시합니다. 캐릭터 사용 기준은 [브랜드 가이드](../ARCAT_BRAND.md)를 따릅니다.
