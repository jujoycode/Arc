# arcat 브랜드 자산

집배원 고양이는 팀의 업무를 전달하는 arcat의 캐릭터입니다. 크림색 바탕에 진저색·차콜색 털 무늬가 있는 **삼색 고양이**이며, 구리색 집배원 모자·차콜 우편 가방·편지가 식별 요소입니다. 제품 버튼·탐색·배경도 같은 색을 바탕으로 구성합니다.

| 자산 | 용도 |
| --- | --- |
| [캐릭터 원본](../../frontend/public/brand/postcat.png) | 로그인·온보딩·상태 안내의 투명 PNG |
| [시선 자세](../../frontend/public/brand/postcat-look.png) | 로그인·가입의 마우스 시선 추적용 얼굴·몸 |
| [눈 가림 자세](../../frontend/public/brand/postcat-private.png) | 비밀번호 필드에 초점을 둘 때의 정지 눈 가림 |
| [편지 전달 자세](../../frontend/public/brand/postcat-delivery.png) | 이메일 확인·초대·티켓 배정 안내 |
| [축하 자세](../../frontend/public/brand/postcat-celebrate.png) | 실제 저장 결과를 안내하는 짧은 축하 |
| [브랜드 마크](../../frontend/public/brand/arcat-mark.png) | 상단 탐색 로고·favicon·터치 아이콘의 투명 PNG |
| [README 배너](arcat-banner.png) | GitHub 제품 소개 |

이미지 생성 도구로 제작한 원본을 그대로 사용합니다. 배너는 브랜드 일러스트이며 [실제 제품 화면 사진](../product/README.md)과 구분합니다. 앱에서는 CSS로 크기를 조절하고 시선·짧은 인사·전달·축하 동작을 적용합니다. 시선 추적은 정밀 포인터·모션 허용 환경에서만 활성화하며 캐릭터에 비밀번호 값을 전달하지 않습니다. 모션 감소·터치 중심 환경에서는 정지 자세를 표시합니다. 캐릭터 사용 기준은 [브랜드 가이드](../ARCAT_BRAND.md)를 따릅니다.
