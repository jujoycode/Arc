## 최신 디자인 방향: 라이트 테마와 제한된 삼색 포인트

사용자의 추가 지시에 따라 큰 배경·패널·내비게이션에는 흰색과 중립적인 밝은 회색을 사용한다. 베이지·크림 배경, 갈색 본문·테두리와 넓은 장식 면은 제거한다. 삼색은 고양이 원본과 로고, 주 행동·선택·포커스 및 차트의 의미 있는 강조에만 쓴다. 입력 경계·본문·메타·비선택 탐색은 중립 회색으로 통일하고 넓은 컬러 면·장식 원·그라데이션을 줄인다.

이번 색상 교정은 새 사용자 지시에 따라 먼저 적용한다. 토큰→로그인·온보딩→앱 셸·HTML 시안 순서로 수정하고 기존 빌드·브라우저·접근성·캐릭터 검증을 실행한다. 기능·조작 크기·간트 좌표는 그대로 유지하며 색상 수정과 검증/실제 화면 자료를 별도 커밋으로 게시한다. 전체 KRDS 치수·컴포넌트 재구성은 별도 작업 단위로 이어간다. 이번 색상 교정에서는 기존 치수와 기능을 유지한다.

사용자는 전체 제품을 KRDS 기반으로 다듬되 기존 기능을 유지하고, 정부 누리집 배너처럼 제품에 필요 없는 요소는 제외하도록 요청했다. 이 문서는 실제 제품 화면 50장과 현행 소스를 검토한 결과를 실행 가능한 작업으로 나눈다. 세부 근거·토큰 대응은 [KRDS 적용 기준](../KRDS_ADOPTION.md), 기존 기능은 [제품 기능과 권한](../product/FEATURES.md)을 따른다.

## 진행 조건과 플러그인 상태

- 사용자가 요청한 Superpowers는 플러그인 검색에서 `installed: true`, `ENABLED`로 확인했다.
- 초기 세션에서는 두 플러그인의 지침이 노출되지 않았지만 재연결 후 Superpowers와 Product Design의 핵심 SKILL.md를 읽었다. Product Design 저장 문맥 preflight 결과는 기존 저장 문맥 없음이며 현재 사용자 요구사항과 코드·토큰·화면을 기준으로 한다.
- 초기 계획 작성 시 두 플러그인을 사용했다고 주장하지 않는다. 연결 후 검증·코드 리뷰 지침과 증거 중심의 화면 확인 기준을 반영했다. Product Design의 일부 공통 참조 문서와 전용 Browser 도구는 제공되지 않아 공식 감사 완료를 주장하지 않으며, 기존 Playwright 수용·실제 사진 촬영으로 이번 교정을 검증한다.
- 라이트 테마 교정은 코드 `0717ff1`에서 완료했고 실제 1920×1080 사진 50장과 [소스 CI 모두 성공](https://github.com/jujoycode/Arc/actions/runs/38123828070)을 확인했다. 공통 UI 규격과 탐색·폼 정비는 적용·검증했으며, 업무 화면과 전체 회귀 검증은 아래 단계로 이어간다.

## 선택한 적용 방식

React 19·shadcn/ui·Tailwind v4·TanStack Query/Table/Router와 Valibot을 유지한다. KRDS의 의미 토큰, 입력·버튼 형태, 레이블과 상태 안내, 키보드·초점·재배치 규칙을 기존 컴포넌트에 적용한다. KRDS의 HTML·JavaScript kit를 별도 UI 런타임으로 추가하지 않는다. 현재 쓰이지 않는 Select·Tabs·Dropdown을 이 작업 때문에 새로 만들지 않는다.

| 대상 | 적용 결정 |
| --- | --- |
| 색상·브랜드 | 흰색·중립 회색의 라이트 테마, 삼색 고양이 유지. 구리색·삼색은 주 행동·선택·포커스·데이터 강조에만 제한 |
| 조작 크기 | 기본 버튼·입력 48px, 밀집 입력·선택 40px, 밀집 버튼 32px. 터치 환경의 주요 버튼 48px·작은 조작 영역 44px 이상 |
| 형태 | 입력·버튼 반경 6px, 카드 10px, 대화상자 12px |
| 글자 | 본문 16px, 입력 16px, 레이블·데이터 15px, 보조 정보 13px. 업무 도구 밀도를 위한 arcat 확장임을 기록 |
| 여백 | 4px 배수, 관련 조작 8px, 그룹 16px, 섹션 24px, 큰 화면 바깥 32px·좁은 화면 24px |
| 정부 전용 요소 | 누리집 배너·태극기·정부 로고·정부기관형 푸터 제외 |
| 앱 전용 요소 | 프로젝트 탐색·공통 필터·간트·WBS·업무 카드·캐릭터를 arcat 패턴으로 정의 |

공식 KRDS의 버튼은 32/40/48/56/64px, 입력은 40/48/56/80px를 제공한다. 32px 입력은 공식 밀집 규격으로 간주하지 않는다. 현재 칸반 카드의 상태 선택 32px는 40px로 정리하는 방향이다. 반경과 글자 크기의 세부 근거 및 가이드와 kit 사이 차이는 적용 기준 문서에 남긴다.

## 변경을 제한하는 계약

계층·부모 자식 접기·필터·집계·관계선·상세 선택·저장 보기·PNG/PDF는 같은 결과를 유지한다. 간트의 행 48px·날짜 헤더 72px와 SVG 좌표 및 `72 + 보이는 행 수 × 48` 출력 계산, 타임라인의 행 88px·막대 위치를 바꾸지 않는다.

OWNER·ADMIN의 기본 관리 권한, 프로젝트별 추가 관리자, 담당자·관리자의 상태/완료율 수정과 모든 팀원의 댓글 권한, 보관 프로젝트의 변경 제한을 유지한다. API·DB·Flyway·Exposed·Query 상태·라우트·정렬·필터 값·폼 스키마·충돌 시 초안 보존을 바꾸지 않는다.

로그인 시선 추적의 상한, 비밀번호 초점 눈 가림, 비밀번호 값과 캐릭터 좌표의 독립성, 터치·모션 감소 정지, 화면 이동 후 이벤트 정리를 유지한다. 로딩·오류·필터 결과 0건을 실제 빈 프로젝트처럼 표현하지 않는다.
